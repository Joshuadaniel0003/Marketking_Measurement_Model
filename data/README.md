# Data

This folder contains the datasets used in the Marketing Measurement Model project.

## Dataset

### `geo_all_channels.csv`

This is a simulated multi-geography marketing dataset used for the Marketing Mix Modeling analysis.

The dataset contains:

- Geography
- Weekly time period
- Channel impressions
- Channel spend
- Control variables
- Conversions
- Revenue per conversion
- Population
- Revenue

### Dataset Dimensions

- 40 geographies
- 156 weeks
- 6,240 observations
- 5 marketing channels

## Processed Dataset

### `meridian_input.csv`

This is the validated and formatted dataset prepared for Google Meridian modeling.

The preprocessing included:

- Data validation
- Missing-value checks
- Duplicate checks
- Negative-value checks
- Time-series validation
- Geography completeness checks
- Media and spend validation
- KPI validation

## Data Usage

The datasets are used only for demonstrating the statistical modeling and marketing measurement workflow developed in this project.

## Source

The dataset is associated with the Google Meridian Marketing Mix Modeling framework.
